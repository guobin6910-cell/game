# 邊境遠征

《邊境遠征》是一個完整的靜態 HTML5 + Phaser 3 第一人稱自動探索角色扮演遊戲。可直接部署到 GitHub Pages：發布此資料夾後開啟 `index.html` 即可遊玩。

## 功能

- 第一人稱自動探索與前進中的道路景觀
- 隨機遭遇、岔路選擇、商店、營火獎勵、菁英與首領
- 回合制戰鬥，包含攻擊、技能、藥水與逃跑指令
- 裝備掉落、稀有度、裝備欄位、背包管理、出售與穿戴
- 升級、經驗曲線、金幣、技能三選一與永久能力
- 使用 `localStorage` 進行本機存檔與讀檔
- 原創 SVG 美術素材與產生式 WAV 音效占位

## 本機執行

啟動靜態伺服器：

```bash
npm start
```

接著開啟 `http://127.0.0.1:8765/`。
