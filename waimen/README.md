# 外門

青衡宗外門雜役的文字冒險。水墨武俠視覺小說，目前收入第一幕第一章〈盤庫〉。

本專案為靜態前端，以 Vite 打包。可直接壓縮上傳到任何靜態空間。

## 開發

於本目錄執行：

```
npm install
npm run dev
```

瀏覽器開啟終端機提示的本機位址（預設 http://localhost:5173 ）。手機與電腦同一區網時，可用終端機列出的區網 IP 在手機瀏覽器遊玩。

## 正式檔（上傳／離線）

```
npm install
npm run build
```

產物在 dist/ 。

- 本機預覽正式檔：`npm run preview`，再以瀏覽器開啟提示位址。
- 純靜態開啟：把 dist/ 放到任何靜態伺服器（Nginx、GitHub Pages、Netlify、或 python3 -m http.server）。因使用 ES module，請不要用 file:// 直接雙擊 index.html。
- 壓縮上傳：可整包壓縮 waimen/（含原始碼），或只壓縮 dist/ 作為上線檔。

vite.config.js 已設 base: './' ，相對路徑，可放在子目錄。

## 操作

- 點擊／觸控畫面推進台詞。打字中再點一次會立刻顯示整句。
- 選項按鈕；鍵盤 Enter／空白鍵推進，數字 1、2、3 對應第幾項。
- 選單可存檔、讀檔、調文字速度。
- 標題：新的故事／繼續（自動存檔）／讀檔（三個欄位）。
- 新的故事選男或女、可填姓名（空白則為無名）。正文中的師兄／師妹依此替換。
- 進度寫入瀏覽器 localStorage（自動＋三欄）。

## 劇本

台詞與分歧在 src/script/chapter1.json 。節點欄位：id、type（line｜choice｜end）、speaker、text、sprite、background、conditions、setFlags、choices、goto。
替換符號：{name} 姓名，{sib} 師兄／師妹。

第一章開頭三選皆為可達路徑，並導向三場不同的夜戲：

1. 「那箱是什麼？」→ 阿禾夜訪、冷饃、箱變輕、內門火漆「不像」
2. 「我沒看見。」→ 油紙包、兩文錢、箋「缺箱之事，已了。好好當差。」
3. 「你知道就該少說。」→ 內門雜役傳話、掃側門、箋「南邊的薦，不是每年都有。今年已滿。」

章末四選（夜探庫房／睡／找阿禾／向謝承淵請安）皆可達。第一章終即止，無偽第二章。
