# 外門

青衡宗外門雜役的**文字RPG**（非視覺小說）。沒有對話框、沒有立繪。頂欄是姓名、氣血、內力、境界；中間是可捲動的記事；底部是行動按鈕。

目前收入第一幕第一章〈盤庫〉，壓縮成可玩的劇情、準備、戰鬥、功法循環。

本專案為靜態前端，以 Vite 打包。設定檔已設相對路徑 base，可放在子目錄。

## 開發與打包

於本目錄執行套件安裝後：

- 開發：執行 package.json 的 dev 指令，瀏覽器開啟提示位址（預設本機 5173 埠）。手機與電腦同一區網時，可用區網位址在手機瀏覽器遊玩。
- 正式檔：執行 build 指令，產物在 dist/。可再用 preview 預覽。
- 純靜態：把 dist/ 放到任何靜態伺服器。因使用 ES module，請不要用本機檔案協定直接雙擊 index.html。

## 怎麼玩

1. 標題：新的故事／繼續（自動存檔）
2. 建立角色：男／女、姓名（空白則為無名）。正文中的師兄／師妹依此替換。
3. 外門樞紐：準備、修煉、開始今日差事、功法冊。可花四文碎銀兌止血散。
4. 準備：出任務前裝備至多三門功法、可帶一包止血散。未裝備功法不能出列。
5. 劇情：記事往下長，底部選項。分岐不合併成同一句。
6. 戰鬥：回合制。選功法、觀招、或丹藥。敵方還手。氣血條與短日誌。勝敗都繼續當差。敗則記過，氣血剩一絲，不是立刻結束。
7. 第一日終了後回外門，不是偽第二章。次日可掃外庭，仍可修煉、翻功法冊。

## 系統

屬性：氣血、內力、攻、防、經驗、碎銀（月例）。境界固定為外門煉體。

功法含類型（攻／守／療／奇）、耗內力、勢、說明。已習清單與出任務裝備（最多三門）分開。

起始功法：

- 青衡樁（守，耗內力低）
- 搬箱勁（攻，雜役搬箱的拙力）

解鎖：

- 聽壁息（奇，聽清對方下一招）——外門修煉
- 掃地掃勢（攻，勢寬）——第一場對趙師兄勝

丹藥：止血散，回氣血。準備時可帶一包。

存檔：瀏覽器 localStorage 自動寫入（屬性、旗標、裝備、場景、性別、姓名）。標題選「繼續」。

## 第一章節奏

掃葉開場，阿禾示警缺箱。三選：問箱／裝瞎／叫他少說。

回外門準備，再赴盤庫。黃耆失蹤，謝承淵攬功。當眾三選：等謝／自認／看阿禾。

罰站之後，外門趙師兄攔路試手（不是謝承淵）。勝：名聲、掃地掃勢。敗：記過，阿禾或自己把你從青石上拽起來。

晚冊，劉三除名。夜：夜探庫房（第二場，對巡夜，可摸到薦字牙牌）／睡／找阿禾／向謝承淵請安。

終了三條路仍開，只是各有側傾。回外門。

## 範圍

僅第一章可玩循環。無立繪。水墨暗青、描金。
